# Moodle Integration

This directory contains learning materials and course integration for the QuFabLab system.

The goal is to integrate the AR Quantenkoffer experiments into structured educational courses.

---

## Purpose

The Moodle resources provide:

- experiment instructions
- theoretical background
- interactive learning content
- exercises and assignments

---

## Possible Course Modules

Examples include:

- introduction to quantum optics
- beam splitter experiments
- interferometry
- photon detection
- AR-assisted experiment learning

---

## Integration Concept

Students perform experiments with the AR Quantenkoffer while following guided instructions in Moodle.

The learning process combines:

- theoretical learning
- hands-on experimentation
- AR visualization

---

## Target Audience

- university physics courses
- STEM education programs
- laboratory courses
- maker education
